The Project: "Apex Digital Bank System"
1. The OOP Setup (Encapsulation)
Create a class named Transaction.

Fields: String type (e.g., "Deposit", "Withdrawal"), double amount, and String timestamp.

Methods: A constructor and a toString() method to display the details nicely.

2. The Core Tasks (Data Structures)
Implement the following features in your Main class:

Task A: The Customer List (ArrayList)
Store the names of the bank's customers. Add 5 names, remove one who "closed their account," and check if a specific name exists in the list.

Task B: The Security Vault (Array)
Define a hardcoded array of 4-digit PINs that are "blacklisted" (e.g., 1111, 1234, 0000).

Task C: The Service Counter (Queue)
Customers are waiting for a loan consultation. Add 3 customers to a LinkedList Queue and "serve" (poll) the first one who arrived.

Task D: The Undo Button (Stack)
Every time a user navigates a menu (e.g., "Home" -> "Settings" -> "Profile"), push the page name onto a Stack. Simulate clicking the "Back" button by popping the last page.

Task E: Unique Transaction IDs (Set)
Use a Random function to generate 10 transaction IDs (between 100 and 110). Store them in a HashSet. Observe how duplicates are automatically handled.

Task F: The High-Priority Fraud Alert (PriorityQueue)
Create a PriorityQueue of transaction amounts. Since large withdrawals are risky, set it up so the largest amount is always at the top to be reviewed first.
